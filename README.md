# Budget Pulse

PWA mobile-first para control financiero diario, mensual y anual con Next.js, Tailwind CSS, Lucide React y Firebase Firestore.

## Desarrollo

1. Instalar dependencias con `npm install`.
2. Ejecutar `npm run dev`.
3. Configurar variables `NEXT_PUBLIC_FIREBASE_*` si se conecta Firestore.

## Estructura

- `src/app` para layout, dashboard, servicios y reportes.
- `src/components` para navegación móvil, FAB, modal y alertas.
- `src/lib` para lógica financiera y Firebase.# cash-flow-pwa
